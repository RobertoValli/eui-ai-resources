# Contributing

Thank you for helping keep this resource accurate and useful to EUI researchers.

## Principles

- Stay close to the existing content, tone, and style when editing established material.
- Distinguish institutional rules from recommendations made by the maintainers.
- Link directly to authoritative EUI sources and cite the relevant section where possible.
- Do not include personal, confidential, or unpublished research data in examples or issues.
- Preserve stable heading identifiers once a page has been published.
- Update the "Modified" line at the end of a page when editing it. Record policy review separately from a routine edit.

## Workflow

1. Create a short branch describing the change.
2. Edit the relevant `.qmd` file.
3. Run `quarto render` and review the affected pages locally.
4. Open a pull request explaining both the change and the source supporting it.
5. Request review from the other maintainer for substantive policy guidance.

Small spelling, link, and formatting corrections can be grouped together. Policy changes and substantive rewrites should remain separate so that they are easy to review.
