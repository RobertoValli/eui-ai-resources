# AI Resources for EUI Researchers

An independently maintained Quarto website offering practical guidance on the use of artificial intelligence in research at the European University Institute.

The site is maintained by the EUI Part-time Assistant Professors of AI, Filip Olsson and Roberto Valli. It complements formal EUI policies and services; it is not itself an official policy source.

## Local preview

Install [Quarto](https://quarto.org/docs/get-started/) and run:

```sh
quarto preview
```

To render the complete site without starting a preview server:

```sh
quarto render
```

Generated files are written to `_site/` and are not committed to the source branch.

## Editing

The four public pages are:

- `index.qmd`: welcome and navigation
- `consultations.qmd`: consultation information
- `eui-resources.qmd`: EUI-specific rules and services
- `getting-started.qmd`: introductory and methodological guidance

Site-wide configuration is in `_quarto.yml`; presentation rules are in `styles.css`.
